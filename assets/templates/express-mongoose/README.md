# {{projectName}}

Express 5 + MongoDB (Mongoose) API in TypeScript, generated by [StackJoist](https://github.com/stackjoist/stackjoist).

## Getting started

Requirements: Node.js 22.13 or newer, {{packageManager}}, and Docker (for the local database) or any MongoDB you can reach.

```bash
{{packageManager}} install            # if you skipped it during setup
docker compose up -d                  # start MongoDB on 127.0.0.1:27017
cp .env.example .env                  # Windows (PowerShell): Copy-Item .env.example .env
{{packageManager}} run dev            # http://127.0.0.1:3000/health
```

## Scripts

| Script                    | Purpose                                                                       |
| ------------------------- | ----------------------------------------------------------------------------- |
| `dev`                     | Start with auto-reload (`tsx watch`)                                          |
| `build`                   | Compile to `dist/`                                                            |
| `start`                   | Run the compiled server                                                       |
| `typecheck`               | Type-check source and tests                                                   |
| `lint`                    | ESLint                                                                        |
| `format` / `format:check` | Prettier                                                                      |
| `test`                    | Unit and HTTP integration tests (uses an in-memory MongoDB, no Docker needed) |

The first test run downloads a MongoDB binary for `mongodb-memory-server`, so it needs internet access once.

## API

| Method | Path                         | Notes                                     |
| ------ | ---------------------------- | ----------------------------------------- |
| GET    | `/health`                    | Liveness                                  |
| GET    | `/health/ready`              | Readiness: 503 until MongoDB is connected |
| GET    | `/api/notes?page=1&limit=20` | `limit` 1–100                             |
| POST   | `/api/notes`                 | `{ "title": string, "body"?: string }`    |
| GET    | `/api/notes/:id`             |                                           |
| PATCH  | `/api/notes/:id`             | Any subset of the create fields           |
| DELETE | `/api/notes/:id`             |                                           |

Errors always look like `{ "error": { "code": "...", "message": "...", "details"?: [...] } }`. Unknown errors return 500 without internal details and are logged.

## Structure

```text
src/
  server.ts        process entry: loads .env, validates config, starts, handles SIGINT/SIGTERM
  start.ts         connects MongoDB, starts HTTP, graceful close
  app.ts           Express app (no network), used directly by tests
  config/env.ts    Zod-validated environment
  db/mongoose.ts   connection management
  lib/             logger, HttpError + input parsing
  middleware/      404 and error handler
  modules/         feature modules (routes -> controller -> service -> model)
test/
  unit/ integration/
```

## Configuration

All settings come from environment variables, validated at startup (see `.env.example` and `src/config/env.ts`). The server refuses to start with invalid configuration or an unreachable database.

## Before going to production

This project is a starting point, not a finished production service. It does **not** include:

- authentication or authorization,
- rate limiting,
- a production MongoDB setup (the Compose file is for local development only, without authentication),
- deployment configuration.

Review these for your use case, and run `typecheck`, `lint`, `test` and `build` in CI.
